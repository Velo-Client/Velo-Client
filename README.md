**Velo Client** is a custom Roblox launcher built to feel like a real standalone gaming client. It focuses on speed, cleanliness, and staying up to date without any manual steps.

It replaces older launchers with a much simpler interface, automatic updates for both itself and Roblox, and a set of quality of life features that make launching Roblox feel modern instead of patched together.

It is lightweight, has no bloat, and is designed to get out of your way once Roblox starts.

This project is for fun. A handful of people maintain it, updates drop whenever we have the time, and there is no pressure to be anything bigger than it is.

## About the Source Code and Security

Velo Client is closed source. The source is not published publicly, mostly for safety and anti theft reasons.

Because the binaries are protected using code obfuscation to prevent unauthorized tampering, **some antivirus programs and Windows SmartScreen may flag the executable as a false positive**. This is normal behavior for obfuscated software. If you trust this repository and the official website, you can safely bypass the warning to run the application.

## Getting Started

1. Open [https://velo-client-app.github.io/velo-client.github.io/](https://velo-client-app.github.io/velo-client.github.io/).
2. Click the download button. It always points at the newest release.
3. Run the application. If SmartScreen or your antivirus warns you, that is the false positive described above.
4. That is it. Velo handles Roblox updates and its own updates from there.
